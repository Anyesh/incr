# Release figures

This lists every measured figure in the 0.2.0-beta.6 section of CHANGELOG.md, so the release integrator can rerun them on the final release sha in one job. Every figure measured on an earlier tree is rerun on the final release sha with the same probe and runner pairing, and the line takes the final numbers.

## How to rerun

The probe figures run as one gh-cmd line, `figures 1.96.1 bash scripts/release-figures/rerun.sh <release-sha>`, on a tip that contains this folder. `probes/probes.tsv` lists each probe file stem with the tree it is compared against (`b5` is the beta.5 tag c61be873c, `main` is b9f0d0bf3, the base this release builds on, and `none` marks an absolute figure) and the CHANGELOG line it measures. `rerun.sh` builds the release sha and only the comparison trees some probe names, copies into each tree only the probes that run there, and builds each probe's test target on its own, so a probe that does not build prints `FIG-BUILD-FAILED <tree> <probe>` with its first errors while the others still run. Each probe then runs `FIGURE_ROUNDS` rounds (3 by default), each round on its comparison tree and then on the release sha, all on one runner, and the output ends with `runner=`.

A new probe is an incr-core integration test file in `probes/` plus a row in `probes.tsv`. It prints lines starting `FIG <tree> <probe> ` followed by key=value figures, taking the tree from `FIGURE_TREE`; the nested chain probe prints `NC <tree> ...` from `NC_TREE`. The beta.5 tree builds with `--cfg fig_b5`, so a probe compared with beta.5 can gate code that needs an API beta.5 lacks (`fan_probe.rs` makes plain queries there, since beta.5 has no `Replay`). A row whose fourth column in `probes.tsv` is `tree` names an incr-core integration test the release tree already has: `rerun.sh` runs it from the tree instead of copying a probe, prints `FIG-MISSING <tree> <probe>` when the tree lacks it, and turns each output line holding ` B per ` into a `FIG` line. `FIGURE_PROBES="a b"` limits a run to the named probes. A probe run that exits non-zero prints `FIG-RUN-FAILED <round-tree> <probe> rc=<n>`, one that exits zero with no figure line prints `FIG-RUN-EMPTY <round-tree> <probe>`, and the output ends with `FIG-DONE failed=<0|1>`; `rerun.sh` exits 1 when any probe is missing, fails to build, fails or prints nothing, so a run without `FIG-DONE failed=0` is not a complete set of figures.
