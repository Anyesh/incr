# Release figures

This lists every measured figure in the 0.2.0-beta.6 section of CHANGELOG.md, so the release integrator can rerun them on the final release sha in one job. Every figure measured on an earlier tree is rerun on the final release sha with the same probe and runner pairing, and the line takes the final numbers.

## How to rerun

The probe figures run as one gh-cmd line, `figures 1.96.1 bash scripts/release-figures/rerun.sh <release-sha>`, on a tip that contains this folder. It builds the beta.5 tag and the release sha on one runner and interleaves 3 rounds of every probe (`FIGURE_ROUNDS` overrides the count).

A new probe is an incr-core integration test file added to `probes/` that builds on both trees and prints lines starting `FIG <tree> ...`, taking the tree from `FIGURE_TREE`; the nested chain probe prints `NC <tree> ...` from `NC_TREE`. Rows whose Remeasure names a gate or an ablation run outside `rerun.sh`.
